## Install (sideload)

1. On your Android phone, download **Bit.apk** from the Assets list below.
2. Open the downloaded file. If Android asks, allow **Install unknown apps** for your browser or file manager (Settings will open for you; turn it on, then go back).
3. Tap **Install**, then **Open**.

You can turn "Install unknown apps" back off afterwards.

Prefer not to install anything? The same app runs in your browser: https://space-paranoids.github.io/tron-bit-mobile/
